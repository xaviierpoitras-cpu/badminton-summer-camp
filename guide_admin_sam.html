03 — Spots

Gestion des places disponibles

Les places sont des sessions supplémentaires que les joueurs peuvent réserver.

1

Ajouter une place

Dans l'onglet Spots, choisis le groupe et la date dans le menu déroulant → clique Add spot. Tu peux ajouter plusieurs places pour la même date (une place = un joueur peut réserver).

2

Voir les réservations

La liste en dessous montre toutes les places. Les places réservées indiquent le nom du joueur et si le paiement a été confirmé.

Advanced 1 Mon 6 Jul Zhengyang Xiao ✅ Paid
Advanced 1 Wed 8 Jul Available
3

Confirmer le paiement d'une session individuelle

Pour chaque spot réservé, tu peux cliquer Mark paid directement sur la ligne pour confirmer que tu as reçu le paiement pour cette session spécifique.

4

Retirer une place

Clique Remove à droite de la ligne. Si la place était réservée, la réservation est annulée automatiquement.

⚠️ Retirer une place réservée annule la réservation du joueur. Contacte-le si un remboursement est nécessaire.
04 — Inscription

Modifier l'inscription d'un joueur

1

Trouver le joueur

Dans l'onglet Payments, repère le joueur dans la liste.

2

Cliquer sur son nom (souligné)

Le nom du joueur est un lien souligné en bleu. Clique dessus pour ouvrir la fenêtre de modification.

3

Modifier et sauvegarder

Tu peux changer : le sous-groupe (Avancé 1/2, Intermédiaire 1/2) et les blocs (Bloc 1, Bloc 2). Clique Save changes.

✅ Les changements sont sauvegardés dans Firebase instantanément. Le joueur voit la mise à jour au prochain chargement.

Générer le PIN

Clique Generate → — un PIN unique est créé automatiquement (vérifie qu'il n'est pas déjà pris).

⚠️ NOTER LE PIN avant de fermer

Une fois le modal fermé, le PIN n'est plus visible en clair (seulement haché dans Firebase). Écris-le immédiatement pour l'envoyer à la famille.

🔴 Le PIN ne peut pas être récupéré après fermeture du modal. Si tu l'oublies, tu dois supprimer le joueur et recommencer.
06 — Permission

Autoriser une réservation inter-groupe

Par défaut, un joueur avancé ne peut réserver que dans les groupes avancés. Cette option lui permet de réserver dans l'autre groupe — une seule fois.

1

Trouver le joueur dans Payments → cliquer son nom

Dans la fenêtre d'édition, tu verras l'option de sous-groupe qui te permet de voir ses paramètres actuels.

2

Activer via la liste des joueurs dans Admin → Spots

Si la liste des joueurs est visible, clique Grant cross-group à côté du joueur. Un badge 🔓 apparaît.

3

Fonctionnement

Dès que le joueur utilise la permission pour réserver dans l'autre groupe, elle est automatiquement révoquée. Tu peux aussi la révoquer manuellement à tout moment.

⚠️ La permission est à usage unique. Si le joueur a besoin d'une deuxième réservation inter-groupe, tu dois l'accorder à nouveau.
